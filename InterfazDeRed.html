iptables Cadena INPUT (Tráfico Entrante) ×

Definición: Evalúa los paquetes de red entrantes cuyo destino final es el propio servidor Bastión (procesos locales, servicios del sistema o almacenamiento interno).

Trayectoria: Nube (WAN) → Interfaz enp0s3 → Reglas INPUT → Proceso Local / Bastión

Ejemplo de uso: Permitir acceso SSH solo desde direcciones IP autorizadas de la nube para administrar el Bastión.

iptables Cadena OUTPUT (Tráfico Saliente) ×

Definición: Filtra los paquetes generados localmente dentro del servidor Bastión dirigidos hacia el exterior o hacia otras redes.

Trayectoria: Servicio Local / Bastión → Reglas OUTPUT → Interfaz enp0s3 → Nube

Ejemplo de uso: Restringir que el Bastión realice conexiones salientes no autorizadas hacia Internet en caso de compromiso.

iptables Cadena FORWARD (Tráfico de Tránsito / Enrutamiento) ×

Definición: Procesa los paquetes que entran por una interfaz de red (ej. enp0s8, enp0s9) y atraviesan el Bastión para salir por otra interfaz (ej. enp0s3) sin ser consumidos por el sistema local.

Trayectoria: Computadora Local / LAN → enp0s8/enp0s9 → Reglas FORWARD → enp0s3 → Nube

Ejemplo de uso: Permitir navegación web desde las computadoras de la LAN hacia la Nube pasando por la inspección del Bastión.

Servidor Bastión ×

Equipo que actúa como punto de conexión y control entre una red externa y una red interna, pudiendo filtrar y reenviar tráfico.

Almacenamiento Disco duro ×

Dispositivo de almacenamiento donde se guardan de forma permanente el sistema operativo, programas y archivos.

Hardware / Kernel Interfaz de red & Controlador (Driver) ×

Componente que permite a un dispositivo conectarse y comunicarse con una red. Puede ser física o virtual; en Linux se identifica con nombres como enp0s3 o enp0s8.

Interfaz de red Interfaz enp0s3 ×

Componente que permite a un dispositivo conectarse y comunicarse con una red. Puede ser física o virtual; en Linux se identifica con nombres como enp0s3 o enp0s8.

Interfaz de red Interfaz enp0s8 ×

Componente que permite a un dispositivo conectarse y comunicarse con una red. Puede ser física o virtual; en Linux se identifica con nombres como enp0s3 o enp0s8.

Interfaz de red Interfaz enp0s9 ×

Componente que permite a un dispositivo conectarse y comunicarse con una red. Puede ser física o virtual; en Linux se identifica con nombres como enp0s3 o enp0s8.

Red Privada Router Local ×

Dispositivo de red que interconecta las computadoras locales de la organización y las comunica con la interfaz privada enp0s8 del Bastión.

WAN Nube ×

Red o conjunto de servicios externos que proporcionan recursos, como Internet, servidores o almacenamiento, a los dispositivos conectados.

Cliente LAN Computadora Local ×

Equipo dentro de la red privada local que requiere salir a la Nube o comunicarse con otros servicios a través del Router y el Bastión mediante la regla de tránsito FORWARD.

Cliente Remoto Computadora Externa ×

Cliente externo conectado a la Nube que intenta acceder a los servicios autorizados expuestos por el Bastión o a la red interna si las reglas de seguridad lo permiten.

Red DHCP ×

Definición: DHCP es un protocolo que permite asignar automáticamente direcciones IP y otros parámetros de configuración de red a los dispositivos conectados.

Linux Netplan ×

Definición: Netplan es una herramienta utilizada en Linux para configurar las interfaces de red mediante archivos de configuración YAML.
